# nrp-docs-candidates

Documentation drafts for the National Repository Platform, kept here while
they are being written and reviewed. Each draft is intended either to be
folded into the official documentation at
[docs.nrp.eosc.cz](https://docs.nrp.eosc.cz), or to be shared with a
selected group of users as a standalone text.

Nothing here is authoritative. A draft may be incomplete, may be superseded
by the official documentation, and may describe behaviour of a particular
repository instance at a particular time. Where a draft and the official
documentation disagree, the official documentation wins.

Each topic lives in its own directory with its own `README.md` explaining
what the draft covers and how far along it is. Drafts are written in Czech
or English depending on their intended audience.
