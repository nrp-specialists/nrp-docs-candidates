Condensed, action-oriented checklist for user groups establishing a
repository in the NRP, in Czech and English. Merges the obligations from
"Conditions for Creating New and Modifying Existing Domain Repositories
in the National Repository Platform" (v3.4) with the lifecycle steps from
the internal Checklist_invenio.xlsx, without duplicating items between
the two sources.

Terminology, architecture and the description of what the NRP itself
provides are deliberately left to the upstream document, which both
files link to.
